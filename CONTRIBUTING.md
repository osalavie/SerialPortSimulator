# 贡献指南 / Contributing

## 中文

- 通过 GitHub Issue 报告问题，附上 Windows 版本、程序版本、复现步骤和预期结果。分享日志前请移除敏感信息。
- 通过 Pull Request 提交修改，每个 PR 聚焦一个问题，说明改动原因、验证步骤和结果。
- 涉及串口或驱动行为时，在 Windows x64 上验证受影响的功能，并说明实际检查了哪些收发或设备操作。
- 只提交有权贡献的内容，保留现有版权和第三方许可声明。提交的内容按对应目录的许可证提供，见 [MIT](LICENSE) 和 [MS-PL](VirtualSerial/LICENSE.microsoft.txt)。

## English

- Report bugs through GitHub Issues. Include the Windows and application versions, reproduction steps, and expected behavior. Remove sensitive information before sharing logs.
- Submit changes through a pull request. Keep each PR focused and describe the reason for the change, the verification steps, and the results.
- For serial or driver changes, verify the affected behavior on Windows x64 and report which communication or device operations you checked.
- Submit only material you have the right to contribute and preserve existing copyright and third-party notices. Contributions use the license for the affected directory. See [MIT](LICENSE) and [MS-PL](VirtualSerial/LICENSE.microsoft.txt).
